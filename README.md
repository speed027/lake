# AI 한입

AI를 처음 접하는 사람이 하루 10분씩 읽고 연습할 수 있는 한국어 입문 학습 사이트입니다.

## 포함된 기능

- AI 기초, 프롬프트, 실전 활용으로 구성된 9개 짧은 레슨과 확인 질문
- 주제별 레슨 필터 및 학습 완료 표시
- 학습 로드맵의 단계별 진도 표시
- 질문을 직접 고쳐 쓰고 이 기기에 저장하는 프롬프트 연습장
- 모바일 하단 메뉴를 포함한 반응형 화면

학습 진도와 연습 내용은 브라우저의 `localStorage`에 저장되며 외부 서버로 전송되지 않습니다. 사이트는 정적 HTML/CSS/JavaScript로 동작합니다.

## 실행

`index.html`을 브라우저에서 바로 열거나, 로컬 서버를 실행하세요.

```powershell
python -m http.server 4173
```

이후 `http://localhost:4173`에 접속합니다.

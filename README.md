# IDEA SPRING

관심 분야와 시작 예산을 조합해 실행 가능한 사업 아이디어를 탐색하는 반응형 웹앱입니다.

## 기술 스택

- HTML5 — 시맨틱 문서 구조
- CSS3 — 반응형 레이아웃, 애니메이션, 디자인 시스템
- Vanilla JavaScript (ES6+) — 필터, 추천 조합, 상세 모달, 로컬 저장
- Google Fonts — DM Sans, Noto Sans KR

## 실행

`index.html`을 브라우저에서 바로 열거나, 로컬 서버를 실행하세요.

```powershell
python -m http.server 4173
```

이후 `http://localhost:4173`에 접속합니다.
